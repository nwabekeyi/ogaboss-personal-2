# Plan: Add TERMINATED Status to Vault

## Goal

Add a `TERMINATED` status to the VaultStatus enum to handle cases when users terminate their vault before the maturity date.

## Changes Required

### 1. Prisma Schema (`vault.prisma`)

Add `TERMINATED` to the `VaultStatus` enum:

```prisma
enum VaultStatus {
  IN_PROGRESS
  COMPLETED
  TERMINATED
}
```

### 2. Vault Service (`vault.service.ts`)

Modify the `unlock` method to:

- Check if current date < maturityDate to determine if it's early termination
- If early termination (date < maturityDate):
  - Set status to `TERMINATED`
  - User receives ONLY the locked amount (no interest - interest is lost)
- If natural completion (date >= maturityDate):
  - Set status to `COMPLETED`
  - User receives locked amount + accrued interest

### 3. Update getUserVaults Query

- Keep filtering for `IN_PROGRESS` only (active vaults)
- Completed/Terminated vaults can be queried separately if needed

## Implementation Order

1. Update Prisma schema with TERMINATED enum value
2. Generate Prisma client
3. Update vault service unlock logic with early termination handling
4. Build and verify
